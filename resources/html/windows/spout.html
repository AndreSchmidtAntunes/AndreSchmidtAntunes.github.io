SPOUT

Spout is a solo university project about a spider on a pilgrimage to the top of the neverending water spout. This project was build in Unity using C#.

To make this project, I was tasked with writing a short story and to develop a playable prototype for it. In total the project was given 4 weeks from planning to final product.

PROCESS

3d sprite rendering

I created my own 3D sprite component to render sprites in 3D space, providing control of how the sprite follows the camera, the z-offset of the sprite in 3D space, and general 2D transformation values. 

void UpdateBillboardState() {
    if (!m_camera || !m_billboardVisual) return;

    Vector3 camera_pos = m_camera.transform.position;
    Vector3 look_target = camera_pos;

    Vector3 dir_to_cam = (m_camera.transform.position - transform.position).normalized;

    m_billboardVisual.position = dir_to_cam * z_offset + transform.position +
                                 (m_offset.x * m_camera.transform.right) + (m_offset.y * m_camera.transform.up);
    if (m_mode == FacingMode.CameraPosition)
        m_billboardVisual.LookAt(look_target);
    else if (m_mode == FacingMode.CameraForward) {
        look_target.y = m_billboardVisual.position.y;
        m_billboardVisual.LookAt(look_target);
    }

    m_billboardVisual.transform.Rotate(Vector3.forward, m_rotation);
    float distance_to_camera = (transform.position - m_camera.transform.position).magnitude;
    float visual_distance_to_camera = (m_billboardVisual.position - m_camera.transform.position).magnitude;
    m_billboardVisual.localScale = Vector3.one * m_scale * visual_distance_to_camera / distance_to_camera;

    if (m_flip) m_billboardVisual.Rotate(0, 180, 0);
}

I used my 3D sprite system to create a rudimentary text box as part of the world-building aspect of this module.

It has 3 modes; text cycling through a list and resetting, cycling every message in the list but then looping the final one, and one that picks a message at random with no back-to-back repeats. 

private void CycleLines() {

    current_line = m_dialogueType switch {
        DialogueType.Cycle =>  
            // Cyclically increments and resets the current line.
            current_line = ++current_line % m_dialogue_lines.Length,
        
        DialogueType.RepeatLast => 
            // Increments and resets the current line, then permanently repeats the last line.
            current_line = Mathf.Min(++current_line, m_dialogue_lines.Length - 1),
        
        DialogueType.CycleRandom =>  
            // Get a random line that isn't the current line.
            current_line = (current_line + Random.Range(1, m_dialogue_lines.Length)) % m_dialogue_lines.Length,
        
        _ => throw new ArgumentOutOfRangeException()
    };
    
    foreach (var tmp in DialogueTMPs) {
        if (tmp.isActiveAndEnabled) tmp.text = m_dialogue_lines[current_line];
    }
}

materials and shaders

All the materials and textures for this project were created using shader-graph.

I tried to invoke an illustrated vibe with these materials by breaking up the straight surfaces. The materials use a mixture of their surface normals alongside the view angle of the camera to create inperfections in the geometry.

water shader

The water shader uses layers of scrolling noise to create a base for the flowing water. It then uses a depth mask to make the water more visible the further in you are looking, which gives a sense of depth. To create some contact foam, I clamp the depth mask to near the surface of the water, and shade that as white.

The effect of the water appearing and disappearing is done with a mixture of 2 methods:

  • Pushing the mesh's vertices in the direction of their normals. The amount to push is relative to some visibility variable.
  • Masking out the entire material with a scrolling noise texture, with the texture being clamped to the same visibility variable.
